# Crammer Agent Workspace

This folder contains reusable context, scripts, hooks, and task playbooks for coding agents working on Crammer.

Start with:

- `../AGENTS.md`: high-level agent instructions.
- `context/project.md`: concise project context.
- `playbooks/*.md`: task-specific workflows.
- `scripts/static-analysis.ps1`: TypeScript/Next validation helper.
- `hooks/post-edit-static-analysis.md`: hook behavior and tuning notes.

The `.claude` folder points at these same scripts so Claude Code and other agents share one source of operational truth.
